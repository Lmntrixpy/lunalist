# Informatikprojekt Hitster-2

Flutter App die das Spielprinzip von Hitster nutzt und mehr Spielmöglichkeiten bietet.

## App Building

```
gh repo clone Lmntrixpy/hitster_final # pull repo via github-cli
cd hitster-final

flutter pub get # get dependencies

flutter clean # clea build cache
flutter build apk --relase # build apk for android
```
